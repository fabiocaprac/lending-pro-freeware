PRAZO CERTO — INSTALAÇÃO NO WINDOWS
===================================

PASSOS (3 ações)

  1. Extraia este ZIP em uma pasta permanente
     (ex.: Documentos, Área de trabalho, disco D:).

     Não extraia em uma pasta temporária. O programa continua nesse
     diretório depois da instalação.

  2. Abra a pasta extraída e dê dois cliques em:

         ┌─────────────────────┐
         │     INSTALL.bat     │
         └─────────────────────┘

     Se o Windows perguntar se deseja permitir o aplicativo, clique em Sim.

  3. Aguarde o fim da instalação (5 a 10 minutos).
     Uma janela preta mostra o progresso. Não a feche.

  → Um atalho "Prazo Certo" aparece na Área de trabalho.
    Dê dois cliques para abrir o app.

O Prazo Certo é um app desktop offline para gestão de crediário,
empréstimos e cobrança. Os dados ficam no seu computador.
